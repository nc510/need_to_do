# 「来斩题 - 在线考试系统」网站使用说明

> 适用范围：`quiz` 题库答题 / `starcoin` 星币道具 / `membership` 会员支付 三个子系统的前台功能。
> 本文面向普通用户（学生、教师），说明各功能从哪里进入、怎么用、有什么限制。
> 若本文与后台实际配置不一致（例如管理员调整了价格、额度、任务奖励），以页面实际显示为准。

---

## 一、网站能做什么

「来斩题」是一个在线练习与考试系统，核心能力分四块：

| 板块 | 解决的问题 |
|------|------------|
| 📝 试卷答题 | 从题库生成/导入试卷，在线作答、自动判分、留档历史成绩 |
| ❌ 错题本 | 答错的题自动收录，按记忆规律提醒复习，连对后可移出 |
| 🏫 班级 | 教师建班发作业/考试，学生加入班级并提交，教师看统计 |
| 🏆 榜单 | 班级榜、个人榜，把努力可视化；⭐ 星币与道具提供额外激励 |

顶部导航栏（导航条右侧）是主要入口，会按身份显示不同菜单：

| 菜单 | 学生可见 | 教师可见 | 说明 |
|------|:--------:|:--------:|------|
| 📋 首页 | ✅ | ✅ | 试卷列表 |
| 📝 我的作业 | ✅ | — | 待完成的班级作业/考试 |
| 🏫 我的班级 | ✅ | — | 我加入的班级 |
| ❌ 错题本 | ✅ | — | 错题复习与组卷 |
| 📊 答题历史 | ✅ | — | 历史答题记录 |
| 🏫 班级管理 | — | ✅ | 建班、发作业、看统计 |
| 📑 我的试卷 | — | ✅ | 我创建/导入的试卷 |
| 🏆 班级榜单 | ✅ | ✅ | 班级风云榜 |
| 👤 用户中心 | ✅ | ✅ | 个人数据总览 + 全部功能入口 |
| 💎 会员状态 | ✅ | ✅ | 会员套餐与开通 |
| ⭐ 星币中心 | ✅ | ✅ | 星币余额、任务、背包、商城 |
| 🔔 通知 | ✅ | ✅ | 系统通知与未读提醒 |

> 「👤 用户中心」是功能最全的一个页面，本文后续提到的绝大部分入口都能在用户中心里找到。

## 二、注册与登录

### 2.1 注册

在导航「📝 注册」进入注册页，需填写：

| 字段 | 是否必填 | 说明 |
|------|:--------:|------|
| 用户名 | ✅ | 登录账号，同时用于试卷归属统计 |
| 邮箱 | ✅ | |
| 手机号码 | ✅ | 需唯一，不能与已有账号重复 |
| QQ号码 | 选填 | |
| 密码 / 确认密码 | ✅ | 两次输入需一致 |
| 姓名 | ✅ | **用于班级名单显示**，建议填写真实姓名 |
| 验证码 | ✅ | 图形验证码，点击图片可刷新 |
| 用户服务协议 / 隐私政策 | ✅ | 需勾选同意 |

提交后账号进入**审核流程**，状态有三种：

- `未审核`（默认）：注册后的初始状态，部分班级/榜单相关功能需审核通过后才计入
- `审核通过`：正常参与班级与榜单统计
- `审核拒绝`：请联系管理员核实

新用户的初始会员状态由后台「会员默认设置」决定；若无特殊配置，即为普通免费用户。

### 2.2 登录与退出

- 导航「🔐 登录」进入登录页，输入用户名 + 密码 + 验证码。
- **单点登录**：同一账号只允许一处在线，新登录会使旧的登录会话失效。
- **登录后会有每日赠礼提示**：当天首次登录会按身份自动发放道具（详见《免费用户与会员权益说明》）。
- 导航「🚪 退出」或用户中心手动退出。

### 2.3 频率限制（防刷）

系统对以下路径做了访问频率限制，触发后会返回 403：

| 页面 | 限制 |
|------|------|
| 登录页 | 1 分钟最多 20 次 |
| 注册页 | 1 分钟最多 10 次 |
| 创建试卷 | 5 分钟最多 10 次 |
| 提交答题 | 1 分钟最多 30 次 |

若机房/校园网共用出口 IP，正常使用一般不会触发；验证码图片接口本身不限流。

## 三、试卷与答题

### 3.1 试卷列表（首页）

「📋 首页」即试卷列表，可按**学科 / 章节 / 知识点 / 出题人**筛选。列表里能看到自己的和公开的试卷。

### 3.2 开始答题

点击试卷进入答题页。答题页支持：

- **断点续答**：中途退出不会丢进度，下次进入可继续未完成的作答（草稿会临时保存）。
- **💡 提示**：持有「答案提示卡」时，可在答题页消耗 1 张查看本题提示（详见第六章道具）。

### 3.3 交卷与成绩

- 交卷后系统自动判分并给出成绩等级。
- 成绩、用时、正确率会写入「📊 答题历史」。

### 3.4 创建试卷（出题与组卷）

从用户中心「📝 出题与组卷」区或相关入口创建试卷，可设置：

| 配置 | 说明 |
|------|------|
| 题目 | 从题库选择/按条件自动组卷 |
| 私有 / 公开 | 私有仅自己可见 |
| 限时 | 是否限制作答时长 |
| 答题次数限制 | 限制可作答次数 |
| 开放时段 | 仅在指定时间段内可作答 |

> 前台创建的试卷若需公开给他人，需要经过审核。测试类试卷可自行使用。

### 3.5 导入试卷

「导入试卷」支持批量导入，**题目的文件格式仅支持 `.xlsx`**；试卷相关页面标注支持 `.xlsx / .xls`，实际以页面提示为准。

导入注意：

- 列名/表头需符合模板要求，请先下载示例文件核对。
- **同一文件 24 小时内重复导入会被拦截**，避免产生重复题目。

### 3.6 答题历史

「📊 答题历史」列出历次作答记录（试卷、得分、正确率、时间），可点击查看单次详情。

## 四、错题本

「❌ 错题本」是提升正确率的核心工具。

### 4.1 错题如何进入错题本

答错的题目会**自动**收录到错题本，无需手动添加。

### 4.2 复习状态

每题有一个复习状态，页面顶部会给出各状态的统计：

| 状态 | 含义 |
|------|------|
| `new` 新错题 | 新收录，尚未复习 |
| `reviewing` 复习中 | 已记录过复习 |
| `difficult` 疑难 | 复习次数较多仍不熟练（第 3 次复习后进入） |
| `mastered` 已掌握 | 已移出错题本练习池 |

### 4.3 连对移出与恢复

- **连续答对 2 次**，题目会被标记为「已掌握」，自动移出错题本练习池。
- 也可以手动「标记为已掌握」移出。
- 移出的题目可随时「恢复」，恢复后连续答对次数清零，重新进入复习池。

### 4.4 间隔复习提醒

记录一次复习后，系统按递增间隔安排下次复习时间：**1 → 3 → 7 → 15 → 30 天**，到期题目会在「待复习」统计中提示。

### 4.5 错题组卷（重点）

在错题本勾选题目后可「一键组卷」，生成专属练习卷。额度规则如下：

| 身份 | 每日次数 | 单次题量 | 说明 |
|------|----------|----------|------|
| 免费用户 | 每天有限次免费额度（默认 1 次，后台可配） | 最多 10 题 | 免费额度用完需用「组卷卡」 |
| 会员 | 不限次数 | 单次仍最多 10 题 | 次数不限，但题量上限同样存在 |
| 任意身份 + 使用组卷卡 | 该次不占用免费额度 | **当次不限题量** | 用卡即解锁本次题量限制 |

- 页面顶部会显示实时的额度提示，例如「🎟️ 今日免费组卷剩余 1/1 次 · 单次最多 10 题」；会员显示「👑 会员不限组卷次数 · 单次最多 10 题」。
- 组卷卡在前台按**道具本名**展示（如「回响之杖」），后台改名后前台自动跟随。
- 每页题数默认 20，可在页面上按需调整（1~100）。

## 五、班级、作业与考试

### 5.1 学生视角

| 入口 | 用途 |
|------|------|
| 📝 我的作业 | 查看待完成的班级作业/考试 |
| 🏫 我的班级 | 我加入的班级列表；未加入时可申请/加入 |

加入班级的方式由班级的加入规则决定：

- **自动加入（auto）**：申请即入班
- **需审核（approval）**：提交申请后等待班级管理员审核

> 若你同时是**班级管理员**又是某班学生，系统会合并两种身份，两边的班级都会出现在你的班级列表中。

### 5.2 教师视角

| 入口 | 用途 |
|------|------|
| 🏫 班级管理 | 创建班级、管理成员、发布作业/考试、查看统计 |
| 📑 我的试卷 | 管理自己创建/导入的试卷 |

- **作业与考试的区别**：
  - 作业：可**反复提交**，提交后可查看解析，适合练习。
  - 考试：需设置**考试时长**，用于正式测验。
- 教师可查看班级的**统计页**与**班级错题导出**（错题明细仅教师可见）。

## 六、星币中心 ⭐

「⭐ 星币中心」是激励体系入口，包含：余额、任务、背包、商城、充值、记录。用户中心的「⭐ 星币中心」区也有对应入口。

### 6.1 星币怎么来（任务奖励）

在「星币中心 → 任务」中可看到任务进度，完成后奖励自动到账。内置任务如下：

| 任务 | 奖励 | 周期 / 上限 |
|------|------|-------------|
| 📅 每日登录 | 5 星币 | 每天一次 |
| 📝 完成试卷 | 3 星币 | 每天一次 |
| 🎯 试卷达标（得分率 ≥ 60%） | 10 星币 | 每天一次 |
| 📋 完成班级作业/考试 | 8 星币 | 每天一次 |
| 🗡️ 斩题奖励（答对一道此前未答对的题） | 1 星币/题 | 每天上限 30 星币 |
| 🔥 连续登录 7 天 | 50 星币 | 每满 7 天一次 |
| 🏅 连续登录 30 天 | 300 星币 | 每满 30 天一次 |
| 📤 分享榜单 | 5 星币 | 每天一次 |

> 任务奖励数值由后台「星币任务」配置决定，可能被管理员调整；任务奖励与是否会员**无关**。

### 6.2 我的背包（`星币中心 → 我的背包`）

背包里是「兑换后已入包」的道具，每张卡都有可用数量。带「使用」按钮的道具（改名卡、头像框）可直接在背包内使用。

### 6.3 道具商城（`星币中心 → 商城`）

商城列出上架道具及其价格；会员价与折扣会在页面上单独标出。道具按下发方式分三类：

| 下发方式 | 兑换后会发生什么 | 包含道具 |
|----------|------------------|----------|
| 即时生效型 | 兑换当次立即生效，无需再操作 | 正确率重置卡、斩题卡、4 张会员卡 |
| 背包使用型 | 先入背包，再到对应场景「使用」消耗 | 改名卡、错题组卷卡、答案提示卡、专属头像框 |
| 人工核销型 | 生成待发放记录，由管理员核销 | 兜底方式，适用于实物类奖品 |

**道具功能一览：**

| 道具 | 分类 | 效果 | 怎么用 |
|------|------|------|--------|
| 🗡️ 名刀·司命 | 功能 | 改名卡，修改一次个人显示名称 | 背包 → 使用 |
| 📜 回响之杖 | 功能 | 错题组卷卡，解锁一次不限题量组卷 | 错题本组卷时自动消耗 |
| 🛡️ 贤者的庇护 | 功能 | 正确率重置卡，重置个人正确率统计 | 兑换即生效 |
| 🌙 破晓·辉月 | 功能 | 答案提示卡，答题时查看一次本题提示 | 答题页 → 💡 提示 |
| 🖼️ 专属头像框 | 装扮 | 为头像激活专属边框（班级榜单等位置展示） | 背包 → 使用 |
| ⚔️ 斩题卡 | 功能 | 直接补记一次斩题数 | 兑换即生效 |
| 🎟️ 1 天体验会员卡 | 特权 | 延长 1 天会员 | 兑换即生效 |
| 🎫 7 天体验会员卡 | 特权 | 延长 7 天会员 | 兑换即生效 |
| 💳 月卡会员卡 | 特权 | 延长 30 天会员 | 兑换即生效 |
| 👑 年卡会员卡 | 特权 | 延长 365 天会员 | 兑换即生效 |

> 价格、会员折扣、库存与限购由后台配置，页面显示为准。会员卡类道具为**无折扣**（避免低价自我续期）。

### 6.4 星币充值（`星币中心 → 充值`）

用人民币充值星币，走支付宝。充值到账后可在「记录」中查看流水。

### 6.5 兑换记录（`星币中心 → 记录`）

查看全部星币变动（任务奖励、充值、兑换、每日赠礼）与道具兑换状态：

- 系统赠送记录会显示绿色「**赠**」标签（消耗 0 星币）。
- 会员价兑换会显示实际折扣与节省的星币数量。

### 6.6 星耀榜（`星币中心 → 星耀榜`）

包含两个子榜，**仅统计学生**：

- 🏅 **星力榜**：看活跃积累
- 🏅 **星富榜**：看当前星币财富

## 七、榜单 🏆

「🏆 班级榜单」展示**班级风云榜**，把班级成员数据聚合成班级总分排名。切换顶部标签可看三个子榜：

| 榜单 | 口径 |
|------|------|
| 🗡️ 斩题榜 | 答对 1 道新题 = 1 分（同题去重） |
| 🏆 得分榜 | 按题目分值累加 |
| 🎯 正确率榜 | 作答满 300 题的班级/个人才参与排名，未达标者单独列出 |

其他要点：

- 榜单**仅统计审核通过的学生**，教师与未审核用户不计入。
- 每个榜单右上角有「📤 分享该榜单 ↗」按钮，会在**新窗口**打开生成的分享图（首次生成分享图可完成「分享榜单」任务）。
- 班级榜同时给出**人均值**，避免只比人数。
- 你自己的名次会在卡片上单独高亮显示（含「我的班级」标记）。

用户中心把个人数据与全部功能入口集中在一页，主要分区块：

| 区块 | 内容 |

| ⭐ 星币中心 | 余额 + 6 个星币功能入口 |

| 📝 出题与组卷 | 创建试卷、导入试卷、导入题目 |

## 十、会员 💎

会员的完整定义、套餐价格与权益差异，请见配套文档：**《免费用户与会员权益说明》**。

## 十一、管理员后台 🛠️

管理员（`is_staff=True`）通过前台用户中心「⚙️ 系统管理 → 管理后台」进入 Django 后台（simpleui 主题）。后台按分组组织，主要分组：

| 分组 | 内容 |
|------|------|
| 👥 用户管理 | 用户、班级、审核状态 |
| 💎 会员与支付 | 充值折扣、会员套餐、会员订单、注册默认会员设置 |
| ⭐ 星币与商城 | 星币账户、道具、道具使用流水、兑换记录、任务、充值订单、登录赠礼、组卷额度 |
| 📝 题库管理 | 题目、知识点、章节等 |
| 📋 试卷管理 | 试卷与试卷题目 |
| 📊 答题记录 | 作答明细与统计 |
| 🏫 班级管理 | 班级成员、作业、考试 |
| 📡 系统监控 | 在线用户、访问日志等 |

后台使用注意：

- **新模型需在 simpleui 菜单白名单中显式登记才会显示**，未登记的分类不会出现在左侧菜单。
- 会员与星币的**流水类数据不建议手工增删**，会破坏「余额 = 流水累加」的可审计性。

## 十二、常见限制与注意事项汇总

1. **答题相关**
   - 题目批量导入仅支持 `.xlsx` 格式。
   - 同一导入文件 24 小时内重复导入会被拦截。
   - 前台创建的公开试卷需审核。
2. **错题本**
   - 连对 2 次即移出练习池，可用「恢复」重新加入（连对次数清零）。
   - 免费用户组卷有每日次数上限，单次最多 10 题；用组卷卡可当次不限题量。
3. **榜单**
   - 仅审核通过的学生上榜，教师不计入。
   - 正确率榜有 300 题作答门槛。
4. **账号与安全**
   - 单点登录：同一账号只能一处在线。
   - 登录/注册/创建试卷/提交答题均有频率限制。
   - 请勿在公共设备保留登录状态。
5. **会员**
   - 会员**不限制登录**，到期后自动回落为免费用户，不影响账号、数据与历史记录。
6. **道具**
   - 背包型道具需到对应场景使用才会消耗，兑换后不会自动生效。
   - 头像框激活后会在支持的展示位（如班级榜单）生效。
7. **权限**
   - 「班级错题明细」等数据仅教师可见。
   - 管理后台入口仅管理员可见。
